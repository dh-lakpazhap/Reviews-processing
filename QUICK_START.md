# Quick Start — Reviews-processing

Краткая инструкция для первого запуска MVP анализа тональности отзывов.

## 1. Подготовить проект

1. Скачайте репозиторий `https://github.com/dh-lakpazhap/Reviews-processing` или откройте уже скачанную папку проекта.
2. Откройте папку `Reviews-processing` в VS Code.
3. Откройте терминал VS Code: **Terminal → New Terminal**.
4. Убедитесь, что терминал открыт в корневой папке проекта — там, где находятся `app.py`, `core.py`, `requirements.txt` и `sentiment_model.joblib`.

Проверьте версию Python:

```bash
python3 --version
```

Для корректной загрузки сохранённой модели используйте ту же версию Python, с которой модель проверялась командой.

## 2. Установить зависимости на macOS

В терминале, находясь в корневой папке проекта, выполните команды по очереди:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

После активации окружения в начале строки терминала обычно появляется `(.venv)`.

## 3. Установить зависимости на Windows

В PowerShell, находясь в корневой папке проекта, выполните:

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

Эти команды используют Python из созданного виртуального окружения.

## 4. Запустить приложение

**macOS** — сначала убедитесь, что виртуальное окружение активировано:

```bash
python -m streamlit run app.py
```

**Windows**:

```powershell
./.venv/Scripts/python.exe -m streamlit run app.py
```

Если Streamlit попросит указать email, оставьте поле пустым и нажмите Enter.

## 5. Открыть приложение и проверить работу

1. Откройте в браузере адрес `Local URL`, который появится в терминале. Обычно это `http://localhost:8501`.
2. Загрузите файл `test_data/valid.csv`.
3. Убедитесь, что приложение обработало 20 отзывов и показало для них метки `negative`, `neutral` или `positive`.
4. Включите фильтр негативных отзывов и проверьте, что остались только строки с меткой `negative`.
5. Отключите фильтр и убедитесь, что снова отображаются все отзывы.
6. Проверьте скачивание полного результата и отдельной выгрузки негативных отзывов.

Для собственного файла используйте CSV в кодировке UTF-8 с колонкой `text`. Для совместимости поддерживается также столбец `content`; если присутствуют оба, используется `text`.

## 6. Завершить работу

Чтобы остановить приложение, вернитесь в терминал, в котором оно запущено, и нажмите **Ctrl+C**. Пока приложение работает, не закрывайте этот терминал.

## Если возникла ошибка

- **`No module named ...`** — проверьте, что виртуальное окружение активировано (macOS), и повторите установку зависимостей из `requirements.txt`.
- **`.venv/bin/python: no such file or directory`** — виртуальное окружение ещё не создано. Выполните шаг 2.
- **Не найдена модель** — проверьте, что `sentiment_model.joblib` находится в корневой папке рядом с `app.py`.
- **Нет столбца с отзывами** — добавьте столбец `text` (рекомендуется) или `content` (для совместимости).
- **Страница не открывается** — проверьте, что приложение продолжает работать в терминале, и используйте адрес `Local URL`, напечатанный Streamlit.

**Важно:** для работы интерфейса не нужно заново обучать модель или скачивать исходный датасет. Приложение использует готовый файл `sentiment_model.joblib`.
